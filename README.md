# calculadora-tempo-gesta-o
Calculadora de Tempo de Gestação

Projeto desenvolvido durante minha graduação em Análise e Desenvolvimento de Sistemas.

SOBRE O PROJETO

Programa desenvolvido em linguagem C que recebe a quantidade de semanas de gestação e calcula uma estimativa aproximada em meses.

TECNOLOGIAS UTILIZADAS
Linguagem C
Lógica de programação
Estruturas básicas de entrada e saída

OBJETIVO
Praticar conceitos básicos de programação, como variáveis, entrada de dados, cálculos e saída de informações.
